## プロジェクト概要
AI-Code-Lint-Fixerは軽量でクロスプラットフォームなコード標準化ツールです。ローカルプロジェクトのコードを一括スキャンし、隠しバグの自動修正、コードスタイルの統一、コメント補完、冗長コードの最適化を実行し、元のビジネスロジックを変更せずにコードの可読性と保守性を向上させます。

本プロジェクトは**継続的に更新・保守されるオープンソースプロジェクト**で、開発者のコード保守コスト削減を目的としています。

## ChatGPT Pro / Codexが必須な理由
無料版モデルでは本ツールの完全機能を実現できません：
- ファイル一括リファクタリングにはPro限定の**超大コンテキストウィンドウ**が必要
- 高精度なバグ検出にはCodexの**専門コードモデル**が必須
- 高頻度一括処理にはProの安定したAPI機能が必要

無料モデルはコンテキスト長とコード解析精度が不十分で、産業レベルの一括最適化に対応できません。

## 主な機能
- `.py` / `.js` ファイルを再帰的に一括スキャン
- 構文エラー・隠し論理バグを自動修正
- インデント・コードスタイルを統一
- ファイル・関数コメントを自動補完
- 冗長コードを最適化（ロジック保持）
- 標準化された修正レポートを自動生成
- 設定不要、ワンクリック実行、マルチプラットフォーム対応

## インストール
```bash
pip install openai
```

## 使用方法
1. OpenAI APIキーを環境変数に設定
2. メインスクリプトを実行
```bash
python main.py
```
