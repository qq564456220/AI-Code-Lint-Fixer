## 프로젝트 개요
AI-Code-Lint-Fixer는 가볍고 크로스플랫폼 코드 표준화 도구입니다. 로컬 프로젝트 코드를 일괄 스캔하여 숨겨진 버그 자동 수정, 코드 스타일 통일, 누락 주석 보완, 중복 코드 최적화를 진행하며, 기존 비즈니스 로직을 유지한 채 코드 가독성과 유지보수성을 높여줍니다.

본 프로젝트는 **지속적으로 업데이트 및 유지보수되는 오픈소스 프로젝트**로, 개발자의 프로젝트 유지보수 비용 절감을 목표로 합니다.

## ChatGPT Pro / Codex 필수 이유
무료 모델로는 본 도구의 완전한 기능을 실행할 수 없습니다:
- 전체 파일 일괄 리팩토링에는 Pro 전용 **초대형 컨텍스트 창**이 필요합니다
- 고정밀 숨겨진 버그 탐지에는 **Codex 전문 코드 모델**이 필수입니다
- 고빈도 일괄 자동화 처리에는 Pro의 안정적인 API 성능이 필요합니다

무료 모델은 컨텍스트 길이와 코드 분석 정확도가 부족하여 산업급 대량 코드 최적화를 지원할 수 없습니다.

## 주요 기능
- `.py` / `.js` 파일 재귀적 일괄 스캔
- 구문 오류 및 숨겨진 논리 버그 자동 수정
- 코드 들여쓰기 및 스타일 통일
- 파일 및 함수 주석 자동 보완
- 중복 코드 최적화 (원본 로직 유지)
- 표준화된 수정 보고서 자동 생성
- 별도 설정 없이 원클릭 실행, 전 플랫폼 지원

## 설치 방법
```bash
pip install openai
```

## 사용 방법
1. OpenAI API 키를 환경변수로 설정합니다
2. 메인 스크립트를 실행합니다
```bash
python main.py
```

## 오픈소스 유지보수 계획
6개월간 지속적인 기능 업데이트 및 반복 개발을 진행합니다:
- 1개월차: 핵심 기능 안정화, 커뮤니티 문서 개선
- 2개월차: Go 언어 지원, 사용자 정의 수정 규칙 추가
- 3개월차: 코드 차이 미리보기, 선택적 수정 기능 추가
- 4개월차: Pro 초대형 컨텍스트 최적화, 대용량 파일 처리 성능 개선
- 5개월차: IDE 연동, 전 플랫폼 환경 적응
- 6개월차: 정식 안정 버전 출시, 장기 유지보수 체계 구축
