## 项目简介
AI-Code-Lint-Fixer 是一款轻量、跨平台的代码规范化开源工具。可批量扫描本地项目代码，自动修复隐性BUG、统一代码风格、补齐缺失注释、精简冗余代码，在不改动原有业务逻辑的前提下，全面提升项目可读性与可维护性。

本项目为**长期开源、持续迭代**项目，致力于帮助全球开发者降低开源项目维护成本、标准化代码质量。

## 为什么必须使用 ChatGPT Pro / Codex
本项目**无法通过免费版模型实现完整功能**：
- 整文件批量代码重构依赖 **Pro专属超大上下文窗口**
- 高精度隐性漏洞检测依赖 **Codex专业代码模型**
- 高频批量自动化处理需要 Pro 稳定API能力

免费模型上下文长度有限、代码解析精度不足，无法支撑工业化批量代码优化场景。

## 核心功能
- 递归批量扫描项目 `.py` / `.js` 代码文件
- 自动修复语法错误、隐性逻辑漏洞
- 统一代码缩进与编码规范
- 自动补全文件、函数层级注释
- 精简冗余代码，保留原始业务逻辑
- 自动生成标准化修复日志报告
- 零配置、一键启动，全平台适配

## 安装依赖
```bash
pip install openai
```

## 使用方法
1. 配置本地 OpenAI API 密钥环境变量
2. 执行入口脚本
```bash
python main.py
```
